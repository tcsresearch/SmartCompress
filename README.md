# SmartCompress
Dynamically check system tools to compress or decompress files and directories based on explicit speed or size criteria.
<br>
This utility will be used by our <a href="https://github.com/tcsresearch/TarMonster-beta">TarMonster</a> project.
<hr>

<p>

> [!NOTE]
> An experimental backup & restore script utilizing several compression/decompression methods.
<hr>

> [!WARNING]
> This code is highly experimental and has NOT been fully implemented or tested yet. <br>
> Testing has gone well so far, and can be considered somewhat suitable for testing, but still lacks most features.
<hr>

> [!IMPORTANT]
> Code is NOT suitable for production, and still lacks most features.
